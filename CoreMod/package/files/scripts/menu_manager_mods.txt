//=========================================================
// MODS - what is installed, and which of it is switched on.
//
// Built on the frame menu_packs.txt uses, because it is the screen in this game that already
// means "pick one of these": the same four mirrored panels, the same plank under the title,
// the same back arrow in the corner.
//
// Only the frame is here. The mods themselves are not: they are whatever is in the mods
// folder on the day, so the tiles, their icons and the detail text are created at run time by
// core.amod through the menu interface. What this file fixes is everything that does not
// depend on which mods a player has - which is also what makes it something you can restyle
// without rebuilding the mod.
//
// Coordinates are the game's own: the origin is the bottom-left of the 640x480 screen and
// $pos is the top-left corner of the thing being placed, so a larger y is further up.
//=========================================================

//The scrollbar is not declared here. The game's $slider is horizontal - its rail, its two
//end arrows and the way it maps a click onto a value all assume it - and this list needs a
//vertical one, which the game has never had. So core.amod draws its own down the right edge
//of the left window and handles the dragging itself. It is written down here rather than
//left to be discovered because this file is otherwise a complete description of the screen,
//and the one piece that is missing from it should say so.
//
//The rail runs from the top of the left window to its bottom, at x = 372, 16 wide.

$text_buttons
{
	//Switches the picked mod on or off. The caption is rewritten at run time to say which of
	//the two it would do, because the button means the opposite of what the mod currently is.
	$button
	{
		$id "ID_MODS_TOGGLE"
		$pos 516 150
		$h_align "center"
		$v_align "center"
		$text "ENABLE"
		$rect_size 180 36

		$help "Switch this mod on or off; it takes effect when you leave this screen"
		$warning ""

		$unreg_enabled 1
		$keyctrl_button 0
	}
}
