Mod.cpp — минимальный мод 
#include <ForgeApi.h>

// точка входа мода
AMOD_EXPORT int __cdecl AmodInit(const AmodApi* api)
{
    if (!Attach(api))
        return AMOD_ERROR_API_VERSION;

    // здесь начинается твой мод
    return AMOD_OK;
}

AMOD_EXPORT void __cdecl AmodShutdown(void) { }

Возможности

Что умеет AzForge

Ставит моды в игру и не ломает её.

Установка за пару минут

Скачал, запустил, играешь: установщик сам найдёт игру и подключит AzForge. Настраивать ничего не нужно.

Файлы игры остаются целыми

Моды живут в своей папке рядом с игрой. Ничего не перезаписывается, а удаление одного файла возвращает всё как было.

Моды под твоим контролем

Список модов прямо в игре: включай и выключай их когда захочешь — игра стартует с тем, что выбрал.

Скорость игры не проседает

Моды — нативный код без скриптовых прослоек: игра работает так же быстро, как и без них.

Можно сделать свой мод

Захотелось создать? В установщике уже есть SDK, готовый пример и плагины для Visual Studio и VS Code.

Документация на двух языках

Гайды и полный справочник API на русском и английском, с примерами кода для каждой подсистемы. Открыть

Установка

Установка — три шага

Установщик содержит всё необходимое и настраивает игру автоматически.

1

Download the installer

Use the button above or browse the release archive — portable zips and earlier versions live there too.

2

Запусти setup.exe

Установщик подключит AzForge к Azangara и пропишет пути. Отдельная настройка не нужна.

3

Запусти игру и включи моды

В списке модов AzForge отметь нужные — они заработают при старте. Захочешь собрать свой — начни с гайда «Быстрый старт».
