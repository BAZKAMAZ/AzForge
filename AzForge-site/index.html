Features

What AzForge does

Puts mods into the game without breaking it.

Set up in minutes

Download, run, play: the installer finds the game and hooks AzForge in. Nothing to configure by hand.

Game files stay intact

Mods live in their own folder next to the game. Nothing is overwritten — removing one file restores everything.

You decide what runs

The in-game mod list lets you switch mods on and off whenever you like — the game starts with what you picked.

No slowdowns

Mods are native code with no scripting layer: the game runs exactly as fast as it does without them.

Make your own mod

Feel like building one? The installer ships with the SDK, a ready sample and plugins for Visual Studio and VS Code.

Docs in two languages

Guides and the full API reference in Russian and English, with code samples for every subsystem. Open

Install

Install in three steps

The installer bundles everything you need and configures the game automatically.

1

Download the installer

Use the button above or browse the release archive — portable zips and earlier versions live there too.

2

Run setup.exe

The installer hooks AzForge into Azangara and sets the paths. No manual configuration needed.

3

Run the game and enable mods

Tick the mods you want in the AzForge mod list — they go live on start. To build your own, start with the Quick start guide.
